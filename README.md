MOMENTUM V4

1. Crea un progetto Supabase.
2. Nel SQL Editor esegui supabase.sql.
3. Recupera Project URL e Publishable key (o anon key) dalle impostazioni/API.
4. Pubblica questa cartella su un hosting HTTPS (GitHub Pages, Netlify, Vercel, ecc.).
5. Apri l'app sul PC, scheda Sync, inserisci URL/key.
6. Crea un account o accedi.
7. Apri la stessa URL sul telefono e accedi con lo stesso account.

I grafici usano le DURATE in minuti: percentuale = minuti categoria / minuti totali registrati.
Non inserire mai una service_role/secret key nel codice del browser.
